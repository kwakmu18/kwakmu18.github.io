- WinDbg 설치 방법에는 크게 3가지가 있다. (더 있나?)

# Windows SDK를 이용한 설치(WinDbg Classic)
- Microsoft에서 제공하는 Windows SDK를 설치하면 WinDbg Classic을 설치할 수 있다.
- Google에 "Windows SDK"를 검색하거나, 아래 링크에 접속한다. (Windows 11 기준)
  - <a href="https://developer.microsoft.com/ko-kr/windows/downloads/windows-sdk/">https://developer.microsoft.com/ko-kr/windows/downloads/windows-sdk/</a>
- 설치 관리자 버튼을 클릭하여 winsdksetup.exe를 다운로드 후 실행하여 설치한다.
  <img src="/assets/img/windbg/1.png" class="post-image">
- 시작 메뉴에서 WinDbg Classic을 찾을 수 있다.<br>
  <img src="/assets/img/windbg/2.png" class="post-image">

# Microsoft 홈페이지에서 설치
- Google에 WinDbg를 검색하거나, 아래 링크에 접속하여 WinDbg 설치 파일을 다운로드할 수 있다.
  - <a href="https://learn.microsoft.com/ko-kr/windows-hardware/drivers/debugger/">https://learn.microsoft.com/ko-kr/windows-hardware/drivers/debugger/</a>
- "WinDbg 다운로드" 버튼을 클릭하여 windbg.appinstaller를 다운로드 후 실행하여 설치한다.<br>
